JD vs Resume: side panel UI, design v2

Built from new light and dark designs. Same features as v1, regrouped: a JD tab and a Resume tab, a summary view, and a Details and Analysis view with the next steps and a Pro Tip. Nothing was removed; what moved is listed at the bottom. Source of truth for every value: tools/jd-capture-extension/panel.css.

The two-colour gradient

TokenLightDarkUsed for
--grad-a coral#fb8b83#f28e84Active tab fill and underline, threshold and match bars, the match ring, gradient borders (Pro Tip), logo, saved banner, primary buttons, selected segments, gradient text
--grad-b amber#ffc376#f6be7d
--grad-angle110deg (the tilt of every gradient)
--grad-text-a/b#e0564c, #d98412#ff9f92, #ffd08aGradient text only: a deeper pair on light so small text stays readable

These were sampled from the bars in your designs. To use your official pair, change --grad-a and --grad-b (once per theme) in panel.css.
