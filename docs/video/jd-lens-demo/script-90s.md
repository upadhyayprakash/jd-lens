# JD Lens demo: 90-second script

Status: draft for approval, 22 Nov 2026. For ElevenLabs (Eleven v3, Stability "Natural"). Tags are sparse on purpose.

- Words: 162. Characters in the ElevenLabs block: 1010 (this is what uses your free credits).
- Pace: about 2.6 words a second, so 162 words is about 62 seconds of speech, and the pauses and screen holds bring it near 90.
- Say the name as "J D Lens". If ElevenLabs reads it oddly, respell it "Jay Dee Lens" in the block only (subtitles keep "JD Lens").
- Do not say any number out loud (scores change; the screen shows them).

## Before you record (setup checklist)

1. Run the helper check so the panel shows "connected" (Settings, Local helper).
2. Save your threshold in Settings (Save threshold), for example 60, so the ring shows on the bar.
3. Vandelay JD: capture it fresh and confirm the text is not truncated (3 requirements and no location was the last capture). Run Get the full score so the assessment exists. The keyword numbers in the application file disagree (67 in the front matter, 83 in the text): re-score so they match before recording.
4. Make the Brag Sheet for Vandelay once (Make Brag Sheet) so the card is filled. Check every line against your memory: it must contain only things you really did.
5. Close other tabs, hide bookmarks, use the same window size for every take. Dark or light, pick one.
6. The master resume HTML and PDF contain your contact details: do not show them in this cut.
